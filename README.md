# Shoes Online Market
Shoes Market is a responsive e-commerce web application built with React and Vite. Users can browse shoes by category, view product details, select sizes, add products to their cart, choose delivery options, and complete a checkout form.

The application uses React Context to manage shared cart, account, and product data. React Router handles navigation between the home page, product pages, account pages, cart, checkout, and protected admin pages.

The admin dashboard includes product, customer, and order management pages. Administrators can add, edit, and delete products, view customer information, review order data, and update order statuses. Customer and order information is stored in a Supabase PostgreSQL database.

The interface was originally designed in Figma and implemented with reusable React components and responsive CSS. The project demonstrates practical experience with component-based architecture, state management, routing, form validation, database integration, and e-commerce user flows.

## Motivation
I built Shoes Market as a portfolio project to strengthen my front-end development skills and gain experience creating a complete e-commerce application.

My goal was to go beyond a simple product listing website and build a project that includes realistic shopping features such as product browsing, filtering, product details, cart management, checkout, account pages, and an admin dashboard.

I also wanted to practice turning a Figma design into a responsive React application while keeping the project structure organized and reusable. During development, I worked with shared components, React Context, protected routes, form handling, local storage, and Supabase database integration.

This project helped me better understand how multiple parts of an e-commerce website work together, including customer-facing pages, cart and checkout flows, product management, customer management, and order management.
